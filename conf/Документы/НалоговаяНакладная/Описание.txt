Документ "Налоговая накладная" предназначен для регистрации 
и формирования печатных форм налоговых накладных, выписанных 
покупателям организации.

Как уже было отмечено, конфигурация позволяет формировать 
как обыкновенные, так и итоговые (сводные) налоговые накладные, 
итоговые налоговые накладные за день по рознице, накладные на 
поставку ниже обычной цены.

Итоговая накладная формируется обычно в конце месяца помощью 
обработки "Формирование налоговых документов".

Для итоговых накладных в табличной части становится видимым и 
доступным реквизит "Дата", который выводится на печать в колонку 2 
и означает дату возникновения налоговых обязательств (т.е. дата 
отгрузки или оплаты, которые были определены как "первое событие").
При формировании документа реквизит "Дата" расчитывается автоматически.
 
Для формирования итоговых налоговых по рознице следует выбрать в 
документе требуемую ставку НДС, установить флажок "Итоговая налоговая 
накладная по рознице за день" и нажать кнопку "Заполнить". Для заполнения 
такой налоговой накладной используется  элемент справочника "Номенклатура", 
задаваемый в константе "Номенклатура для итоговых налоговых накладных по 
рознице".

 Для заполнения налоговых накладных при поставке ниже обычной цены следует:
     - сначала ввести обычную налоговую накладную
     - копированием создать еще одну налоговую накладную, в ней установить флаг "Продажа по 
 цене ниже обычной" и указать обычные цены в табличной части. Для такой 
 накладной формируются проводки на сумму доначисленного НДС исходя из обычной цены.   
 Тип причины "Оставляем у себя" такой налоговой накладной должен быть 15. 
 Только из этого документа можно распечатать и выгрузить налоговую накладную 
 "на превышение обычной цены".

Выписка обыкновенных налоговых накладных может выполнять-
ся в типовой конфигурации как в режиме "ввода на основании", так 
с помощью обработки "Формирование налоговых документов". При 
вводе на основании многострочной "Банковской выписки" докумен-
том будет предложено выбрать соответствующую строку из нее, при 
автоматическом формировании- будет сформировано требуемое ко-
личество налоговых накладных.

Рассмотрим теперь спецификацию электронной формы документа 
и процесс ее заполнения, в зависимости от различных режимов его 
формирования.

Реквизиты шапки "Налоговой накладной" будут по умолчанию 
заполнены из документа-основания (документа долга).

В одном документе "Налоговая накладная" могут присутствовать 
только товары с одной ставкой НДС, кроме случая,  когда присутствуют 
ставки "20%" и "0%." При этом реквизит шапки "Ставка НДС"
должен иметь значение 20% и необходимо установить 
флажок "Есть нулевые ставки НДС". Для выбора ставки заполняется 
реквизит шапки "Ставка НДС". Он может иметь значение "0%", "20%",  "7%" и 
"Без НДС". 
Отметим, что спецификация как автоматически сформированной "Нало-
говой накладной", так и введенной в режиме "ввода на основании", будет 
заполнена по умолчанию из документа-заказа того документа, проведение 
которого инициировало ее формирование (на основании которого она 
была введена).

Если табличная часть документа-основания (или документа дол-
га) содержала товары с разными ставками НДС, то в режиме автома-
тического формирования будет сформировано несколько налоговых 
накладных с различными ставками НДС, в режиме "ввода на осно-
вании" - будет предложено осуществить выбор той ставки НДС, по 
которой она будет сформирована.
 
Если в документе - заказе присутствуют товары, у которых вид 
товара - "Услуга" и в карточке такого товара отмечено "Считать 
услугу транспортной затратой", то такие товары попадут в таблич-
ную часть "Налоговой накладной" (но не в печатную форму), а в 
печатной форме суммы по этим товарам попадут в строку "Товаро - 
транспортні витрати".

В реквизиты шапки документа закладки "Основные" и "Допол-
нительно" вносится следующая информация:
	- наименование организации - покупателя;
	- договор и документ-счет по тому документу, на основании 
которого вводится налоговая накладная;
	- валюта и курс этой валюты по отношению к гривне;
	- ставка НДС, может иметь значение "0%", "20%", "7%" и "Без НДС";
	- сумма возвратной тары без НДС;
	- наименование проданных объектов (товары, запасы или 
необоротные активы);
	- вид торговли;
	- сотрудник, который выписал текущую накладную (по 
умолчанию будет подставлено значение константы "Кто 
обычно выписывает налоговые накладные").
	- родительский документ - собственно тот документ, на ос-
новании которого была введена "Налоговая накладная" 
(который инициировал ее формирование при групповом 
формировании). Для итоговых налоговых накладных этот 
реквизит останется незаполненным.

Если налоговая накладная выписывается в соответствии с п. 8.3
Порядка, реквизиты продавца и покупателя в документе должны
совпадать. Для этого в справочнике "Контрагенты" следует создать
элемент с реквизитами (наименование, ИНН, номер свидетельства)
соответствующими реквизитам фирмы.

На закладке "Дополнительно" в реквизите "Документ-
основание" отобразится наименование того документа, который 
явился основанием для выписки налоговой накладной.    

При формировании налоговых документов цены,указанные в 
расходной накладной, пересчитываются в соответствии со 
ставкой НДС. В связи с этим возможны расхождения между 
ценами указанными в расходной накладной и ценами 
расчитанными в налоговой накладной.
Для того чтобы в печатной форме налоговой накладной 
обеспечить совпадение суммы и значения произведения 
Цена на Количество используется реквизит "Пересчитать 
при печати" . Он позволяет правильно рассчитать (в зависимости 
от значения) цену или количество. 
Если выбрано значение "Не пересчитывать" то пересчет не будет
выполняться. Если выбрано значение "По цене" то будет 
подобрана наиболее близкая цена. Если выбрано значение
"По количеству" то будет подобрано наиболее близкое количество.
Если выбрано значение "По цене, количеству" то сначал будет 
подобраться цена, потом количество. Если выбрано значение 
"По количеству, цене" то будет сначала  подобраться количество,
потом цена.

При заполнении табличной части "Налоговой накладной", как 
при ее автоматическом формировании, так и при "вводе на основа-
нии" могут использоваться значения таких констант как "Авансовый 
платеж" и "Частичная отгрузка". Это происходит в случаях, когда 
определение номенклатурного состава табличной части затрудни-
тельно, а именно:
	- Если клиент выполняет предоплату по счету, но сумма 
предоплаты превышает сумму по счету. В этом случае 
табличная часть соответствующей "Налоговой наклад-
ной" будет содержать одну строку, графа "ТМЦ" которой 
будет заполнена значением константы "Авансовый пла-
теж", графа "Сумма +"- суммой платежа с НДС. 
	- Если контрагент выполняет оплату за уже отгруженную 
ему продукцию (товары, услуги), но сумма оплаты пре-
вышает сумму отгрузки. В этом случае графа "ТМЦ" бу-
дет заполнена значением константы "Авансовый платеж", 
а в графе "Сумма +" - сумма "по первому событию".
	- Если "Налоговая накладная" выписывается при возник-
новении "первого события" в момент отгрузки, но при 
этом сумма "по первому событию" не совпадает с итого-
вой суммой расходного документа. Например, клиентом 
была выполнена предоплата по выписанному ему "Счету" 
на сумму 120 грн. (НДС составил 60 грн.) После этого 
"Расходной накладной" оформляется отгрузка на сумму 
480 грн. (НДС 80 грн.). Сумма первого события составит 
в этом случае 360 грн. Именно на такую сумму будет 
сформирована "Налоговая накладная". Сумма 360 гри-
вень будет оформлена в "Налоговой накладной" как 
"Частичная отгрузка".

Во всех остальных случаях табличная часть будет заполнена в со-
ответствии с табличной частью документа-счета или родительского 
документа.

При проведении документ "Налоговая накладная" не формирует бухгал-
терских проводок (кроме режима поставки ниже обычной цены), но 
для того, чтобы она была включена в реестр накладных, 
документ необходимо проводить.

Все проведенные документы отражаются в отчете "Реестр налоговых
накладных". 
На закладке Дополнительно выводится наименование контрагента, 
которое будет выводиться в графе 5 "Реестра налоговых накладных".  
Для его корректировки надо установить флаг "Изменить наименование
для графы 5". Если флаг установлен, то наименование не заполняется
автоматически при изменении контрагента.
Для отражения в "Реестре налоговых накладных" документа с видом 
"ВМД",  на закладке Дополнительно установите флаг "ГТД" и заполните 
"Номер ГТД".  Флаг доступен только для операции "Экспорт".            

Если в документе установлен дополнительно флаг "Включено в уточняющий
расчет к Декларации по НДС", то в отчете "Декларация по НДС" документ 
отражаться не будет, в отчете "Реестр налоговых накладных"
в колонке "Вид документа" будет добавлен признак уточняющего ("У"). 
Отчет "Уточняющий расчет к Декларации по НДС" необходимо заполнить 
вручную.  

Все сформированные "Налоговые накладные" помещаются в 
журнал "Книга продаж".
