Для регистрации изменений количественных и стоимостных по-
казателей выписанных покупателю налоговых накладных, а также 
для формирования печатной формы соответствующего документа 
("Расчет корректировки") в типовой конфигурации предусмотрен 
документ "Приложение №2".

Документ может быть введен только на основании документа 
"Налоговая накладная". Реквизиты шапки полностью заполняются 
из документа - основания.

Значения реквизитов "ТМЦ", "Ед", "Кво", "Цена -" табличной 
части документа заполняются из документа-основания. В остальных 
реквизитах табличной части указывается следующая информация:
	- причина корректировки, необходимая при формировании 
печатной формы документа;
	- изменение количества по выбранному товару;
	- изменение цены без НДС по выбранному товару;
	- изменение суммы НДС;
	- изменение суммы без НДС (базы налогообложения).

Реквизит табличной части "Номер строки из Налоговой накладной" 
заполняется автоматически порядковым номером строки. 
ВНИМАНИЕ! Этот номер может не соответствовать номеру строки  
из распечатанной/ выгруженной налоговой накладной.  

Отметим, в соответствии с действующим законодательством, кор-
ректировку по товару можно проводить либо по цене, либо по коли-
честву. Если "Приложение № 2" было введено на основании итоговой
налоговой накладной по рознице (установлен флажок "Итоговое по 
поставке в рознице"), количество и цена не доступны,
и корректировка проводится изменением сумм.

При формировании налоговых документов цены, указанные в 
накладных, пересчитываются в соответствии со 
ставкой НДС. В связи с этим возможны расхождения между 
ценами указанными в накладных и ценами расчитанными 
в Приложении 2.
Для того чтобы в печатной форме Приложения 2
обеспечить совпадение суммы и значения произведения 
Цена на Количество используется реквизит "Пересчитать 
при печати" . Он позволяет правильно рассчитать (в зависимости 
от значения) цену или количество. 
Если выбрано значение "Не пересчитывать" то пересчет не будет
выполняться. Если выбрано значение "По цене" то будет 
подобрана наиболее близкая цена. Если выбрано значение
"По количеству" то будет подобрано наиболее близкое количество.
Если выбрано значение "По цене, количеству" то сначал будет 
подобраться цена, потом количество. Если выбрано значение 
"По количеству, цене" то будет сначала  подобраться количество,
потом цена.

При проведении документ не формирует бухгалтерских проводок, 
но для того, чтобы документ попал в отчет "Реестр налоговых
накладных", он должен быть проведен.

Если в документе установлен дополнительно флаг "Включено в 
уточняющий расчет к Декларации по НДС", то в отчете "Декларация 
по НДС" документ отражаться не будет. 
Отчет "Уточняющий расчет к Декларации по НДС" необходимо 
заполнить вручную. 

Все сформированные документы "Приложение № 2" хранятся в 
журнале "Книга продаж".
