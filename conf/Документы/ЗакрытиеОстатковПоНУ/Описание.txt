Документ "Закрытие остатков счетов налогового учета (налог на прибыль 2015)" 

В соответствии со ст. 138, 140 НКУ, все разницы, связанные с приобретением 
(созданием) запасов, начисляются в периоде приобретения (создания), влияют 
на налогооблагаемую прибыль этого периода и не влияют на определение 
себестоимости реализации (списания) запаса. 
Поэтому не ведется учет стоимости запасов по данным налогового учета. 
   
Начиная с 01.01.2015, НКУ не предусматривает начисления доходов и затрат 
по данным налогового учета для определения налогооблагаемой прибыли.   
Поэтому не ведется учет на счетах Н7-Н9-го классов после 01.01.2015. 

Для документов учета капитальных инвестиций, запасов, доходов и затрат, 
введенных до обновления на релиз 7.70.313 есть проводки по счетам 
налогового учета.

Данный документ предназначен для закрытия остатков по счетам 
налогового учета в 2015 году. 

ВАЖНО! Проводки по счетам налогового учета Н2-го, Н7-Н9-го классов, 
счете Н15, не влияют на начисление разниц и определение
налогооблагаемой прибыли. 
Выполнять очистку неиспользуемых счетов налогового учета необязательно.
