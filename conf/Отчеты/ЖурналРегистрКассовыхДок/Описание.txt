Для формирования журнала регистрации приходных и расходных кассовых 
документов в национальной валюте в типовой конфигурации предназначен 
отчет "Журнал кассовых документов". 
Для составления отчета следует выбрать пункт "Журнал кассовых 
документов" в меню "Отчеты" главного меню и в форме ввода указать 
период (дату), за которую необходимо сформировать отчет и  кассу, для 
которой будет сформирован настоящий отчет.
Касса выбирается из справочника "Счета нашей фирмы", таким обра-
зом можно получить кассовую книгу для каждой кассы отдельно. Если 
реквизит "Касса" диалоговой формы запроса оставить незаполненным, то 
отчет сформируется по всем гривневым кассам.
Для формирования отчета необходимо нажать кнопку "ОК" или кноп-
ку "Сформировать".
Сформированный отчет открывается в виде табличного документа, 
который может затем быть выведен на печать. При использовании кнопки 
"ОК" после формирования окно формы настройки параметров отчета за-
крывается. При использовании кнопки "Сформировать" окно остается 
открытым, что позволяет изменить параметры отчета и сформировать 
другой отчет.
Сформированный отчет будет содержать остатки на начало даты по 30 
счету по выбранной кассе (или по всем кассам фирмы), все проводки по 
30 счету по выбранной кассе за эту дату.
