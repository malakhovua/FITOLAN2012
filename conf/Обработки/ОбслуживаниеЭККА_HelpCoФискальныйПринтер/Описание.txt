Настройка кассового аппарата для системы 1С:Предприятие 
заключается в задании списка параметров и их значений.

Параметры.
УпрощенныйПротокол - если параметр равен 1, то для работы с ЭККА используется 
                                упрощенный протокол. Упрощенный протокол необходим при 
				     работе с фискальным регистратором "Мини ФП". Также его реко-
				     мендуется использовать в ОС Windows 2000.
НомерКассы	    - логический номер кассы заданный в программе Session Manager 
                       		Config (Конфигуратор менеджера сессий), которая поставляется 
                       		вместе с драйвером. При работе по упрощенному протоколу в этот 
				     параметр нужно записать комбинацию номер порта, физический номер 
				     кассы (число;число). Например, для работы с кассой через COM1 нужно 
			           указать "1;0"
Пользователь     - имя пользователя, как оно задано в кассовом аппарате.
Пароль			- пароль пользователя, как он задан в кассовом аппарате.
Сервер                - сетевое имя компьютера, на котором установлен кассовый аппарат. 
                               Используется в случае, когда кассовый аппарат установлен на 
				     удаленном компьютере. 

Названия параметров следует записывать в точности так, как указано выше
(с учетом регистра символов).
