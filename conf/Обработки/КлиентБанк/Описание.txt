     Обработка "Обмен данными между ПП "1С" и "Клиент-Банк"" предназначена для экспорта 
платежных документов за период из "1С:Предприятия" в систему типа "Клиент-банка", а также
для импорта операций по расчетным счетам в "1С:Предприятие" из "Клиент-Банка".  
Подробное описание формата файлов обмена  и алгоритмов обработки данных импорта/экспорта
содержиться в документе "Стандарт обмена данными "1С:Предприятие" - "Клиент-Банк" ".  

Обработка работает в конфигурациях:
- Бухгалтерский учет для Украины;
- Комплексная конфигурация для Украины;
- Производство+Услуги+Бухгалтерия для Украины;
- Торговля+Склад  для Украины;

В начале процедуры экспорта/импорта данных необходимо указать вид операции обмена данными.
Возможные варианты значений вида операции:
- Импорт проведенных банком платежных документов;
- Экспорт платежных документов в систему "Клиент-Банк" ;


1. Экспорт платежных документов из "1С:Предприятия" в систему "Клиент-Банк" .

На Шаге 1 при  экспорте платежных документов в систему "Клиент-Банк" необходимо указать
список расчетных счетов, по которым платежные документы экспортируются, а также указать
виды платежных  документов, учавствующих в обмене данными.    

На Шаге 2  необходимо указать интервал дат, за который будет производиться экспорт. 
А также формат обмена (TXT, XML), вид кодировки для текстового формата ( WINDOWS, DOS)
и файл для экспорта данных.
По умолчанию название файла  экспорта для txt-формата  - 1c_to_kb.txt  
По умолчанию название файла  экспорта для xml-формата - 1c_to_cb.xml   

После указания всех необходимых данных, для заполнения файла экспорта нужно нажать
кнопку "Экспорт>".
После окончания выгрузки можно просмотреть результат. Для этого нажмите 
кнопку "Просмотр".
                  

2. Импорт операций по расчетным счетам в "1С:Предприятие" из "Клиент-Банка" .  
   
На Шаге 1 при  импорте операций по расчетным счетам из системы "Клиент-банк" необходимо
указать список расчетных счетов, по которым платежные документы импортируются, а также
указать виды платежных  документов, учавствующих в обмене данными.    

На Шаге 2  необходимо указать формат обмена (TXT, XML), вид кодировки для текстового формата
( WINDOWS, DOS)  и файл для импорта данных.
По умолчанию название файла импорта для txt-формата  - kb_to_1c.txt  
По умолчанию название файла импорта для xml-формата - cb_to_1c.xml   

На этом шаге можно предварительно просмотреть содержимое файла импорта. Для этого нажмите 
кнопку "Просмотр".

На Шаге 3  необходимо выбрать бухгалтерские счета, которые будут указаны в сформированных
Банковских выписках.
По умолчанию предлагаются следующие значения бухгалтерских счетов:
- Для отображения поступивших платежей:  361;
- Для отображения расходования средств:   631;  

Для конфигурации "Торговля+Склад для Украины" бухгалтерские счета не используются.

На этом же шаге нужно указать способ заполнения Банковских выписок.
Нужно указать один из вариантов значений:
- Перед заполнением удалить все строки из табличной части документа;
- Добавлять новые стоки к ранее введенным (т.е старые не удалять); 

На Шаге 4  после указания всех необходимых данных, для осуществления импорта нужно нажать
кнопку "Импорт". 
По ходу процесса загрузки данных в  "1С:Предприятие" будут выводиться строки информационных
сообщений о результатах каждого выполненного обработкой действия.  

После окончания загрузки будут сформированы и заполнены документы:
- Платежные поручения;
- Платежные требования-поручения;
- Банковские выписки;

Все недостающие в файле импорта реквизиты будут заполнены в этих документах значениями
"по умолчанию".
Все нераспознанные по коду ОКПО контрагенты будут добавлены в справочник "Контрагенты"
в папку "Новые (клиент-банк)".  

Для просмотра результата импорта необходимо открыть журналы "Платежные документы"  и "Банк".
В процессе загрузки данных обрабатываемые платежные документы проводятся сразу.
Банковские выписки заполняются, но остаются непроведенными.

Перед проведением Банковских выписок необходимо проверить правильность заполнения
реквизитов табличной части, а отсутствующие реквизиты (например: Заказ, Документ-основание)
указать вручную.

Правила синхронизации (согласования) загружаемых из "Клиент-Банка" данных  с документами
уже существующими в "1С:Предприятие",  определены  "Стандартом обмена данными
"1С:Предприятие" - "Клиент-Банк" ".
